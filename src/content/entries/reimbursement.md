很多人以為核銷是計畫做完後，才把所有發票整理好交出去。但其實<strong>核銷從經費編列的時候就開始了</strong>。因為你決定把錢花在哪裡、付給誰、採用什麼方式付款時，也就決定了後來需要哪些證明資料。

核銷不只是證明「這筆錢有花出去」，還需要讓別人可以確認：<strong>支出符合核定用途、發生在允許期間內，而且有可以查核的紀錄。</strong>

不論是補助案或標案，都需要有經費依據。以補助案為例，假設原本申請補助 20 萬元，最後只核定 10 萬元，就不能直接沿用原本申請的經費表；必須確認核定函及核定經費表，看看哪些工作項目與金額獲得核准。若是標案，則要對照契約、標價清單及相關請款規定。

<strong>以下以「補助案」的核銷方式為例。</strong>

<div class="claim-pathway" aria-label="補助經費核銷的四個階段">
  <div><span>01</span><strong>核定函</strong><small>確認期間與項目</small></div>
  <div><span>02</span><strong>原始憑證</strong><small>蒐集交易與付款證明</small></div>
  <div><span>03</span><strong>支出明細</strong><small>整理每筆經費</small></div>
  <div><span>04</span><strong>黏貼憑證</strong><small>編號、歸檔與核章</small></div>

上圖是隱匿部分基本資訊的核定函公文。第一個可以注意的地方，是<strong>發文日期：民國 115 年 8 月 5 日</strong>。接著還要閱讀主旨與說明，確認計畫從什麼時候開始、核定了哪些工作，以及有沒有附帶修正或核銷條件。

有些核定函會直接寫清楚補助金額、限定的經費項目，或要求先修正經費表，這時候就需要依照核定內容處理。

<div class="claim-note">
  <strong>發文日期，不一定等於可以開始核銷的日期</strong>
  <p>核定函的日期是判讀的起點，但實際的支用起迄日，仍應看公文、核定計畫、補助簡章與相關規定。不能只因為公文在某一天發出，就認定從那天開始的所有花費都能核銷。</p>
</div>

## 二、認識原始憑證

看過核定函，你可能已經知道計畫能使用經費的期間、受補助的經費項目與金額。接下來要弄懂的是：究竟什麼是「原始憑證」？

原始憑證是經濟業務發生時取得或填製，用來記錄和證明交易發生或完成的單據。簡單來說，就是<strong>計畫經費花用的證明</strong>，例如發票、收據、領款憑單、電子發票、車票、農民收據、工作費領據等。

這些憑證有不同的形式。一般商店可能開立統一發票、電子發票、免用統一發票收據，或其他依法開立的交易憑證；支付給個人的勞務報酬，則可能需要使用領款憑單。

### 什麼時候使用領款憑單？

領款憑單的使用時機，主要取決於<strong>「錢是付給誰」以及「對方能提供什麼合法憑證」</strong>。

| 付款情況 | 通常如何準備憑證 |
| --- | --- |
| <strong>支付個人勞務所得</strong> | 例如外聘講師的講座鐘點費、專家出席費、個人撰稿的稿費，依規定取得個人領據或領款憑單 |
| <strong>向公司或店家購買</strong> | 例如餐點、文具、場地租借，通常取得對方依法開立的發票或收據 |
| <strong>搭乘大眾運輸或郵寄</strong> | 依適用規定取得車票、購票證明或郵資相關憑證 |
| <strong>小規模經營者或個人工作室</strong> | 先確認對方依法應提供的憑證與補助單位是否接受，不能直接以自製領據替代 |

可以先用一句話記住取得憑證的方向：

<div class="claim-memory-line">有發票拿發票，沒發票簽領據。</div>

不過，這只是方便記憶的口訣，<strong>不是所有沒有發票的交易都能改簽領據</strong>。實際仍須依交易性質、支付對象及補助規定判斷。

### 領據／領款憑單製作

在核銷實務中，領款憑單是用來記錄個人領取款項的重要憑證。製作時，最需要確認的是以下三組資訊：

| 欄位 | 應確認的內容 |
| --- | --- |
| <strong>支領原因</strong> | 哪一項計畫、哪個工作項目，以及為什麼要支付 |
| <strong>受款人資料</strong> | 姓名，及依法辦理所得申報、付款查核所需的身分與聯絡資料 |
| <strong>款項資訊</strong> | 領取事由（如講座鐘點費、出席費）、支付金額及必要的扣繳欄位 |
| <strong>日期與簽章</strong> | 領款或支付日期、受款人簽名或適用的付款證明 |

金額可以依表格需要同時寫阿拉伯數字與國字大寫，以避免辨識不清或遭到塗改。

以上領款憑單可以看到「領款金額」、「代扣稅額」、「代扣健保」、「實領淨額」等欄位。這些欄位與所得稅、二代健保有關，屬於另外需要釐清的付款與申報問題；這裡先把重點放在<strong>每筆支付能否留下完整、可核對的原始憑證</strong>。

收款人填寫完成、簽署領款資料後，請依規定妥善保存，不要把含有身分證字號、地址、電話或簽章的原始文件直接公開。

<div class="claim-note">
  <strong>小提醒｜領款資料寫錯怎麼辦？</strong>
  <p>領款憑單或其他原始憑證如果有塗改，可能產生查核疑義；尤其涉及金額、受款人與日期等重要資訊時，更應謹慎。比較穩妥的做法，是依補助單位及會計規定重新取得正確的憑證，不要自行塗改後就認定可以核銷。</p>
</div>

## 三、經費支出明細

確認原始憑證都已整理好後，接下來就需要製作<strong>經費支出明細</strong>。不同計畫可能使用「經費結報表」、「經費收支明細表」等名稱，但目的都是讓審查或會計人員理解：你的計畫核定補助什麼、最後實際花了多少，以及每筆款項如何歸類。

  </a>
  <figcaption>經費結報表參考圖片｜依所申請計畫提供的正式格式填寫</figcaption>
</figure>

首先，要確認結報表上的計畫名稱、核定補助文號及補助金額，是否與收到的核定函相符；如需單位用印，也要檢查印章是否清楚、完整。以上圖片就是可以觀察核章位置及經費欄位的例子。

接著最重要的，是把每個經費項目依序填入收支明細。

<div class="claim-compare">
  <strong>建議三份資料使用相同的項目順序</strong>
  <div><span>核定經費表</span><span>經費支出明細</span><span>黏貼憑證</span></div>
  <p>例如核定經費表第一項是「策展人費」，那麼支出明細也先列策展人費，黏貼憑證再按同樣順序整理。這樣會計人員比較容易逐項查帳，團隊自己核對金額時，也不容易漏掉單據。</p>
</div>

## 四、黏貼憑證

有了原始憑證與經費支出明細，接下來就可以整理黏貼憑證了。

「黏貼憑證用紙」（有時簡稱黏貼憑證）是集中整理發票、收據或個人領據的文件。它不只是把單據貼起來，也會搭配經費科目、用途說明及必要的簽名核章，讓這些支出可以依序查核。

一張黏貼憑證用紙，通常包含以下區塊：

| 欄位 | 要填寫什麼？ |
| --- | --- |
| <strong>編號</strong> | 依經費支出明細的順序編排，讓每張單據能找到對應項目 |
| <strong>金額</strong> | 這張黏貼憑證所附原始憑證的合計金額 |
| <strong>用途說明</strong> | 記錄這筆費用花在哪裡；有自籌款或核准的勻支，也可依格式註明 |
| <strong>憑證黏貼區</strong> | 整齊放置發票、收據、領款憑單等 |
| <strong>科目欄</strong> | 依核定項目填寫，例如「業務費－印刷費」 |
| <strong>核章區</strong> | 依表格要求，由經辦、會計、負責人等適用人員簽核 |

一張用紙能放幾張單據，通常要看紙張大小、單據尺寸與機關格式。從整理經驗來說，如果一張紙放到六至八張以上，就可能逐漸不方便檢查；<strong>這是整理上的建議，不是統一規定的張數上限</strong>。

### 多張單據貼在同一張時，怎麼編號？

例如一個經費項目在支出明細中編號為「9」，而這一組共有第 25 至第 32 張單據，那麼這張黏貼憑證就可以標為 <strong>9-25～32</strong>。整理時，也可以依單位規定在各張原始憑證不影響必要內容的位置，標上 <strong>9-25、9-26、9-27</strong> 等對應編號。

無論最後採紙本黏貼或電子憑證整理，最重要的都是<strong>憑證編號、經費支出明細與核定項目能夠互相對應</strong>。實際需要送交哪些文件、是否須提供正本、如何保存，仍要以補助機關的要求為準。
