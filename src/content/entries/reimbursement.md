「活動已經辦完，發票也拿到了，為什麼還不能報帳？」、「講師費已經付出去了，現在才發現沒有請講師簽領據，該怎麼辦？」這些都是第一次執行政府計畫時，很容易遇到的事情。

很多人以為核銷是計畫做完後，才把所有發票整理好交出去。但其實**核銷從[經費編列](/local-practice-guide/entries/budget-planning/)的時候就開始了**。因為你決定把錢花在哪裡、付給誰、採用什麼方式付款時，也就決定了後來需要哪些證明資料。

核銷不只是證明「這筆錢有花出去」，還需要讓別人可以確認：**支出符合核定用途、發生在允許期間內，而且有可以查核的紀錄。**

## 一、先看核定函：哪些支出可以核銷？

計畫通過後，通常會收到核定通知或簽訂契約。這份文件的重要性不只在於告訴你獲得多少補助，更要拿來確認**支用期間、核定經費、工作項目與結報要求**。

  <span class="reimburse-label">每筆付款前，先問四件事</span>
  <div class="reimburse-question-grid">
    <p><strong>時間</strong><small>這筆支出是否在核准的支用期間內？</small></p>

    <p><strong>文件</strong><small>對方能提供什麼憑證？是否需其他證明？</small></p>
  </div>

**不是看到核定函的發文日期，就一定能從那一天開始核銷。** 有些計畫另訂執行起迄日、可追溯支用期間或特定費用限制，應以正式核定內容及相關規定為準。

同樣地，預算表有編列一筆費用，也不代表不論怎麼花都能核銷。購買前應回頭確認項目、單價或比例限制；若需要[勻支或流用](/local-practice-guide/entries/budget-planning/)，應先完成計畫要求的申請或核准程序。

## 二、認識原始憑證：證明這筆支出確實發生

所謂**原始憑證**，就是用來記錄及證明交易或支付確實發生的資料。它可能是統一發票、合法收據、符合規定的個人領據、交通票證或其他支付文件。

不同付款對象，適合取得的憑證也不同。

| 付款情況 | 常見憑證或紀錄 | 需要注意 |
| --- | --- | --- |
| **向公司、店家購買** | 發票、免用統一發票收據或其他合法交易憑證 | 確認品項、金額、日期及應載買受人資訊 |
| **支付個人講師費、稿費、出席費** | 領款憑單或符合規定的領據，搭配授課、出席等紀錄 | 確認收款人、所得性質與必要扣繳 |
| **搭乘大眾運輸** | 車票、購票或搭乘證明等適用資料 | 是否可報支、需要哪些出差紀錄，依該案規定 |
| **郵寄文件** | 郵資收據或相關證明 | 說明寄送用途，確認與計畫相關 |
| **聘請臨時人員** | 工資與出勤紀錄、領據或支付證明等 | 還要注意實際聘僱關係及勞動、保險義務 |

每筆費用都應有明確的付款對象與可追溯的支出紀錄。**沒有發票，不代表一定能改用領款憑單。** 是否允許使用收據或領據，取決於交易對象、所得性質以及補助機關的規定，不能為了核銷方便而自行換成另一種單據。

<div class="reimburse-callout">
  <strong>拿到發票或收據，先檢查再收起來</strong>
  <p>看看日期、品名、數量、金額及買受人資訊是否正確；如有統一編號或其他指定欄位，也應依適用規定核對。等到結案才發現資料不齊，往往很難補救。</p>
</div>

## 三、領款憑單怎麼做？

當款項是支付給自然人，例如邀請外聘講師授課、請人撰稿或參與符合規定的諮詢會議，對方未必能開立發票。這時可能需要請收款人簽署**領款憑單**，讓單位有資料可以證明款項支付的對象、原因與金額。

領款憑單通常應確認以下內容：

| 欄位 | 要記錄什麼？ |
| --- | --- |
| **支領原因** | 哪個計畫、哪個工作項目、為何支付 |
| **收款人資料** | 姓名及依所得申報、查核需要的必要資料 |
| **款項性質** | 講師鐘點費、稿費、出席費或其他適用名目 |
| **金額** | 應支付金額及必要時的代扣、實領資訊 |
| **日期** | 支領或付款日期 |
| **簽名或收款證明** | 依規定取得受款人簽章、匯款或其他付款紀錄 |

以上只是認識欄位的示意，不是任何機關指定的正式表單。**領款憑單也不等同於所有情況都能使用的「支出證明單」**；不同文件有不同用途，應優先使用計畫提供的格式。

另外，領款憑單可能涉及身分證字號、地址等個人資料。請依實際申報及查核需求蒐集、妥善保存，**不要把未遮蔽的領據、身分證資料或簽名放進公開成果報告**。

## 四、經費結報表：把預算與實際支出對起來

單筆憑證整理完成後，還需要把整個計畫的經費統整。這時就會使用**經費結報表**。多數計畫會提供指定格式，讓你將核定預算與實際支出逐項對照。

| 項目 | 核定經費 | 實際支出 | 備註 |
| --- | ---: | ---: | --- |
| 講師鐘點費 | 12,000 元 | 12,000 元 | 依原規劃辦理 |
| 材料費 | 5,000 元 | 4,000 元 | 實際採購金額較低 |
| 場地租借費 | 3,000 元 | 3,000 元 | 依原規劃辦理 |
| **合計** | **20,000 元** | **19,000 元** | **差額 1,000 元** |

<small>以上為虛構的計算示例，正式結報表通常還會依規定區分補助款、自籌款及其他欄位。</small>

填寫時應確認：有沒有使用正確的核定表、是否逐筆登錄支出、補助款與自籌款是否分清楚，以及金額能否回頭對應憑證。

如果有核准的勻支、流用或經費變更，應按照該計畫格式在備註說明，必要時附上核准文件。至於**核定補助文號**，應依真正的核定函填寫，不是自行編一組號碼。需要用印的表格，也要確認印章及簽核是否清楚、完整。

<div class="reimburse-callout">
  <strong>一筆費用可能同時使用補助款與自籌款</strong>
  <p>假設材料費的合法支出憑證為 <strong>3,000 元</strong>，其中補助款負擔 <strong>2,000 元</strong>、自籌款負擔 <strong>1,000 元</strong>。憑證所證明的交易金額仍是 3,000 元，不能因為只申請補助 2,000 元，就把發票金額改成 2,000 元。實際如何在結報表及黏貼憑證上呈現，依該計畫格式處理。</p>
</div>

## 五、黏貼憑證：讓每張單據找得到位置

經費結報表整理的是整案帳目；**黏貼憑證用紙**則用來把單筆或同類支出的發票、收據、領據，連同科目、用途與簽核紀錄整理在一起。

常見欄位包括：

| 欄位 | 填寫方式 |
| --- | --- |
| **憑證編號** | 對應結報表與單據，方便查找；編法依單位制度 |
| **業務計畫／會計科目** | 填寫核定的計畫名稱及適用經費項目 |
| **金額** | 填寫所附憑證合計金額，並與單據相符 |
| **用途說明** | 簡短寫出這筆支出用在什麼工作 |
| **附件或黏貼區** | 按照單位及補助機關要求整理單據 |
| **簽核區** | 經辦、驗收、會計或負責人等適用核章欄位 |

黏貼憑證並非只是把發票貼在紙上，它還要讓核銷經辦者知道這筆錢屬於哪個計畫、哪個科目、用在哪裡，以及經過哪些必要確認。紙本黏貼、電子憑證與核章流程可能不同，請使用該案或組織指定的方式。

## 六、個人所得扣繳與補充保費，別等付款後才問

支付給個人的講師費、稿費或其他勞務報酬，不只涉及領款憑單，也可能牽涉所得分類、**所得稅扣繳**以及**二代健保補充保費**。

這兩種不是同一筆款項：

| 項目 | 主要涉及 | 核銷前要確認 |
| --- | --- | --- |
| **所得稅扣繳** | 國稅局及所得稅規定 | 給付的所得類別、適用扣繳規定、申報及繳納義務 |
| **補充保險費** | 健保署及全民健康保險規定 | 給付性質、適用門檻、是否需要代扣及單位負擔 |

不是所有個人領款都一律扣相同百分比，也不能只憑「講師費」三個字就決定所得類別。**扣繳稅額、補充保費與實際領到的金額，可能不同於約定的給付總額**；付款前要先確認，並保留相應紀錄。

這些規定會隨給付類型、適用年度及法令變動，詳細內容可另參考[〈二代健保補充保費〉](/local-practice-guide/entries/supplemental-premium/)。本篇先聚焦核銷流程，不把個別年度的稅率或起扣門檻當成通用答案。

## 七、送件之前，再對一次

<div class="reimburse-final-check">
  <div><span>01</span><p>每筆支出都在核准期間內，且符合經費科目與規定。</p></div>
  <div><span>02</span><p>發票、收據、領據等原始憑證齊全，資訊與金額正確。</p></div>
  <div><span>03</span><p>需要的付款、授課、出勤或其他工作完成紀錄已整理。</p></div>
  <div><span>04</span><p>經費結報表金額、補助款與自籌款分配，能對應實際憑證。</p></div>
  <div><span>05</span><p>憑證編號、用途說明及必要核章完整；核准變更也有留存。</p></div>
  <div><span>06</span><p>確認是送交原始憑證、影本、電子資料，或按規定自行保存備查。</p></div>
</div>

計畫的經費結報方式不盡相同。有的要求提交全部憑證，有的採清單結報並由受補助單位保存；政府採購案的驗收請款，也不等同於補助案結報。**實際需要送什麼、怎麼裝訂與保存多久，仍應依當年度規定及契約辦理。**

  <p>從申請、編列、實際付款到最後結報，每一步都應讓人能追溯：「這筆錢為什麼花、花給誰、花在哪個項目、憑什麼證明？」</p>
