一個計畫從申請、審查、核定到執行，終於完成了課程、活動、訪談、調查，或一項地方公共行動。接下來，卻又遇到另一個問題：「成果報告到底要怎麼寫？」

最常見的寫法，是把每一場活動的日期、照片、參加人數依序放進報告，再寫上「活動圓滿成功」。但是，**辦完活動，不一定代表達成計畫原本想解決的問題**；而報告很厚，也不代表能讓審查者理解你的工作。

如果說[〈計畫撰寫〉](/local-practice-guide/entries/proposal-writing/)是把尚未發生的事情說清楚，那麼成果報告就是反過來回答：

> 當初承諾做什麼？實際完成了多少？過程中發生哪些變化？留下哪些成果與證據？還有哪些事情沒有完成？

  <div><span>01</span><strong>原本承諾</strong><small>核定計畫、契約與績效指標</small></div>
  <div><span>02</span><strong>實際執行</strong><small>場次、人數、作品與工作紀錄</small></div>
  <div><span>03</span><strong>提出證據</strong><small>簽到表、問卷、會議紀錄、成果物</small></div>
  <div><span>04</span><strong>說明改變</strong><small>成效、限制、調整與後續方向</small></div>
</div>

## 一、成果報告不是活動流水帳

寫成果報告的目的，不只是證明「我們有做事」，而是讓沒有參與計畫的人，也能從報告理解工作如何回應當初的計畫目標。

| 容易寫成流水帳 | 成果報告更需要回答 |
| --- | --- |
| 8 月 12 日辦理一場課程 | 為什麼安排這堂課？它對應哪一項目標？ |
| 邀請三位講師授課 | 選擇這些主題與講者，是為了回應什麼需求？ |
| 共有 13 人參與 | 原本預計多少人？實到人數如何確認？ |
| 活動得到良好反應 | 問卷或回饋具體指出什麼？有沒有不符合預期的地方？ |
| 附上許多活動照片 | 照片能否辨識活動、日期、工作內容與完成情形？ |

例如，地方青年財務培力課程如果只寫「邀請專家分享風險管理、創業法規，活動順利完成」，讀者仍不會知道這項工作究竟帶來什麼。若加入學員對自由接案、工作室、勞健保及鄉村收入條件的回饋，就能進一步說明：哪些內容真正符合需求，又有哪些教學方法還需要修正。

**成果報告要同時交代「做了什麼」與「為什麼重要」，但後者必須有實際紀錄支持。**

## 二、動筆以前，先找回核定計畫

成果報告的起點不是新開一份 Word，而是**找出最後核定的計畫書或契約**。如果計畫期間曾經辦理工作項目、預算、期程的變更，也要一併找到核准紀錄。

| 必須先拿出來的資料 | 要確認的事情 |
| --- | --- |
| **核定計畫書／契約** | 原定目標、工作項目、數量、品質要求、履約內容 |
| **審查或修正紀錄** | 哪些工項、期程或承諾曾經正式調整 |
| **期中／期末報告格式** | 機關要求哪些章節、表格、檔案與送件期限 |
| **績效指標表** | 場次、人次、份數、面積、作品及其他承諾如何計算 |
| **經費核定表及變更資料** | 核定經費、科目調整、支用期間與結報要求 |

如果是[補助案](/local-practice-guide/entries/subsidy-guide/)，要以核定內容與補助規定為準；如果是[標案](/local-practice-guide/entries/tender/)，則須對照契約的履約標的、查核點及驗收條件。不要拿最早送出的提案版本作為唯一基準，因為後來可能已經核定修正。

<div class="report-reading-note">
  <strong>先分清楚：期中與期末不是同一份報告</strong>
  <p><b>期中報告</b>重點在於目前做到哪裡、是否符合這個階段的查核要求、工作有無落後，以及下一階段準備如何推進。<b>期末報告</b>則要回頭對照整個計畫期間的承諾，說明最終成果、達成狀況、限制及後續延續方式。</p>
  <p>尚未到執行期限的工作，不必寫成「未達標」；但如果原本已經到期卻尚未完成，就應說明原因及處理方式。不同計畫的期中、期末及結案要求可能不同，仍應以正式文件為準。</p>
</div>

## 三、成果報告的章節怎麼安排？

每個機關可能提供不同的格式，**只要有規定，就應優先遵守**。沒有制式格式時，可以依照下面的架構整理。

| 章節 | 要寫的重點 |
| --- | --- |
| **前言或成果綜述** | 計畫原本要處理什麼問題、這一階段完成什麼、整體判斷 |
| **計畫進度表** | 每項工作原定數量、實際執行、完成或未完成狀態 |
| **執行情形說明** | 各工作項目的目的、做法、過程、實際產出與活動紀錄 |
| **執行成效** | 工作之間產生哪些連結？對參與者、團隊或地方有何影響？ |
| **遭遇困境與問題分析** | 哪些事情不如預期、原因為何、採取哪些調整 |
| **質化及量化 KPI** | 將原定指標與實際數據放在一起，說明統計基礎 |
| **經費執行情形** | 依規定對照核定預算、實際支出與結報文件 |
| **附件及佐證紀錄** | 簽到表、問卷、成果照片、出版品、會議紀錄及其他證據 |

以「山下線・地方生活指南」115 年期中報告為例，先以進度表總覽各項工作，再依「課程與工作坊、教育與教材研發、社區與公民行動、生態與農業行動」四大類別說明，接著整理整體執行成效、遭遇困境、質化及量化指標，最後才放入大量附件。這種寫法的優點，是讀者可以**先掌握整體，再往下查每個項目的細節與證據**。

### 前言應該先寫，還是最後才寫？

建議先整理成果、再回頭完成前言。因為前言並不是把計畫書的申請動機重貼一次，而是要讓讀者快速知道：**這段期間究竟完成哪些事情、現階段最重要的成果是什麼、後面還要做什麼。**

## 四、量化績效：把「原本承諾」與「實際完成」放在一起

計畫最容易被檢核的部分，是量化指標，例如活動場次、課程時數、參與人次、出版份數、完成面積或合作單位數。

可以先製作一張表，把核定計畫的目標和實際完成情形對照。以下取自「山下線・地方生活指南」115 年期中報告的進度表，示範不同類型的指標如何呈現：

**場次超標，不代表成果就一定比較好。** 例如原本預計辦 15 場，實際辦 21 場，仍要問：這 21 場是否對應原定目的？更多場次是否真的增加參與機會？又是否因為辦太多，影響原先其他工作？

### 場次、人次、人數，不要混在一起

| 指標 | 計算方式 |
| --- | --- |
| 場次 | 實際辦理幾場活動 |
| 人次 | 每場參與者加總，同一人參加不同場可重複計入 |
| 人數 | 不重複計算的實際參與人數，須確認統計方法 |
| 份數 | 完成並可辨識的手冊、報告、圖資或成果物 |
| 達成率 | 實際完成 ÷ 原定目標；是否採累計或分期須先確認 |

有報名資料，不代表人真的到場；有活動照片，也不一定能證明實際人數。若報告前後數字不同，例如進度表、內文、附件的場次不一致，要回到簽到資料與工作紀錄重新確認，不要為了讓數字好看而直接修改。

## 五、質化成效：不只寫滿意，更要交代改變

質化成果不是在量化表格之外多寫幾段感想。它要回答的是：**原本存在什麼問題？計畫做了什麼？因為這個行動，出現哪些可以觀察的改變？還有哪些限制？**

<div class="report-outcome-steps" aria-label="質化成果四階段寫作方法">
  <div><span>原本狀態</span><p>地方原本面對什麼需求、缺口或困境？</p></div>
  <div><span>實際介入</span><p>採用什麼方法，與哪些人一起行動？</p></div>
  <div><span>可見改變</span><p>回饋、行動、作品或合作關係出現什麼變化？</p></div>
  <div><span>仍待觀察</span><p>哪些目標尚未實現？需要多久才能判斷？</p></div>
</div>

### 案例一：兒童社區地圖，不只是一場活動

在山下線的兒童社區地圖工作坊中，近 60 名學童參與，調查顯示有 **89% 的受訪學童認為社區缺乏遊玩空間**。如果只寫「完成一場兒童工作坊」，這些孩子對生活環境的觀察就不會出現在成果之中。

但如果將孩子標記的遊玩場域、昏暗道路、野狗出沒位置及可求助的對象整理起來，就能說明：這項工作讓成人平常較少聽見的兒童空間需求，成為可以討論的公共議題。

<div class="report-case-card">
  <span class="report-case-label">從活動成果，到公共議題</span>
  <p><strong>完成的工作：</strong>兒童參與社區地圖共創與生活空間調查。</p>
  <p><strong>看見的問題：</strong>受訪學童反映遊憩空間不足，並指出日常路線上的安全問題。</p>
  <p><strong>初步成效：</strong>把孩子的生活經驗整理成後續公共空間討論可使用的資料。</p>
  <p><strong>還不能宣稱：</strong>完成工作坊，就代表村落已經有新的遊玩場所。</p>
</div>

### 案例二：串連不只是大家認識彼此

「東區百大文化基地及青年見學」期中報告中，七腳川文化廊道已辦理兩次串聯會議，讓不同團隊討論既有田野資料、文化教育方法與資料共享，並開始形成共享資料與授權運用的共識。

這比「辦理兩場交流會議」更能說明成效；但同樣要區分：**建立合作共識，不等於文化廊道已經完成**。若成果仍在規劃與媒合階段，就應以「形成合作基礎」或「進入共同討論」描述，而不是直接寫成長期網絡已經成熟。

## 六、每一個工作項目，怎麼寫得完整？

可以用五個問題整理每一項工作的文字：

<div class="report-five-grid">
  <div><span>01</span><strong>目的</strong><p>原本想解決什麼問題？</p></div>
  <div><span>02</span><strong>做法</strong><p>辦了什麼，與誰合作？</p></div>
  <div><span>03</span><strong>數量</strong><p>何時、多少場、多少人？</p></div>
  <div><span>04</span><strong>結果</strong><p>留下什麼成果與回饋？</p></div>
  <div><span>05</span><strong>反思</strong><p>有何不足，下一步怎麼辦？</p></div>
</div>

例如「東區百大文化基地及青年見學」期中報告中的一場文化基地體驗工作坊，實際有 **15 人參與、回收 11 份有效問卷**，問卷中「是否更加認識百大文化基地」的平均評價為 **4.91 分**。

撰寫時，不妨先交代工作坊如何安排導覽與體驗，使參與者認識地方文化，再寫參與規模及問卷結果；最後引用問卷中對「文化交流、資源串連、促進理解」等面向的回饋，討論活動是否達到原定的文化擴展目標。

這樣的內容，比單純寫「活動滿意度很高、深受好評」更具體，也能讓審查者知道你的判斷從何而來。**但問卷分數只能代表受訪者的回饋，不能直接推論所有參與者都已產生長期行為改變。**

## 七、遭遇困境與調整，不要省略

不少人會擔心把問題寫進成果報告，讓審查者覺得執行不佳，因此只留下成功的部分。但任何需要和地方居民、合作單位、天候與行政制度一起工作的計畫，都可能遭遇變動。

比起把困難藏起來，更重要的是交代清楚：

<div class="report-problem-chain" aria-label="困境問題的整理順序">
  <span>遇到什麼情況</span><span>為什麼發生</span><span>採取哪些調整</span><span>對原計畫的影響</span><span>下一階段怎麼辦</span>
</div>

### 案例：原本要做手冊，後來開始思考數位知識庫

「山下線・地方生活指南」原先規劃整合地方實踐手冊，希望讓地方工作經驗可以被其他團隊學習。但隨著生成式 AI 與線上知識查詢方式發展，團隊也開始反思：固定出版的手冊，是否方便讀者查詢與長期更新？

這個問題不是一句「因應 AI 發展，計畫轉型」就能帶過。報告應說明原先的目的仍是知識傳承、當前已完成四種教材、面對紙本更新成本及使用習慣的變化，下一階段準備評估紙本、網站與 AI 輔助查詢的方式。

**已完成的成果，要寫成已完成；還在評估的方向，就應寫成正在評估。** 不要把未完成的數位系統寫成已正式上線，也不要把原本承諾的成果直接從報告中刪掉。若涉及核定工作項目或交付形式變動，仍須依該計畫規定辦理變更。

## 八、附件、經費與送件前的檢查

成果報告不是把正文寫完就好。**正文提出一項成果，附件應盡可能找得到對應證據。** 最簡單的做法，是按照工作項目建立資料夾，並讓各項資料有一致的名稱及編號。

| 成果類型 | 可整理的佐證資料 |
| --- | --- |
| 課程、工作坊 | 活動流程、日期與地點、簽到表、照片、課程成果與問卷 |
| 訪談、田野調查 | 訪綱、訪談紀錄、整理成果、必要的授權或同意文件 |
| 社群與跨單位串連 | 會議紀錄、參與單位、討論決議、後續共作紀錄 |
| 教材、手冊、地圖 | 實際成品、檔案或印製照片、使用及公開情形 |
| 空間改善、棲地維護 | 施作範圍、前後照片、工作紀錄、維護及監測資料 |
| 經費執行與結報 | 核定經費表、依規定應備的支出憑證、調整核准紀錄及結算表 |

活動照片最好有足以辨識內容的圖說，不只是放一張大家坐在教室裡的照片。問卷應說明有效份數與統計方式；涉及受訪者、孩童或個人資料，公開報告及附件時也應注意隱私與授權。

### 成果報告和經費核銷，是相關但不同的工作

成果報告回答「工作完成了什麼」，經費結報回答「核定款項如何支用」。有些案件會要求兩者一起送件，有些則另有會計查核或結報程序；不要因為成果照片充足，就認為可以取代發票、收據等支出憑證，也不要以為核銷完成，就代表履約成果不需要再接受檢核。

經費細節可另閱讀[〈經費編列〉](/local-practice-guide/entries/budget-planning/)與[〈核銷方式〉](/local-practice-guide/entries/reimbursement/)。

  <p><strong>成果報告最重要的，不是讓每一件事情看起來都很成功，而是把實際發生的事情說清楚。</strong>那些有成果的工作，應該有證據；遇到困難的工作，也應該有誠實的分析。</p>
