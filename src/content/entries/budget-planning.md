計畫書撰寫中，新手最常遇到的問題，往往是「經費應該怎麼編列？」有時候不是不知道要做什麼，而是想像不到辦一場活動究竟需要哪些經費。像是講師費、材料費、保險、交通、場地、臨時工資，還有活動結束後才想到的清潔費，都是執行工作可能要面對的成本。

**經費表不是先把補助金額填滿，而是把想做的事情，轉換成可以估算、執行與核銷的支出。** 如果你還沒有概念，可以先從不同工作項目的需求開始對照。

<div class="budget-route" aria-label="經費編列的四個步驟">
  <div><span>01</span><strong>確認工作</strong><small>要辦什麼、辦幾場、多少人</small></div>
  <div><span>02</span><strong>拆解資源</strong><small>人力、場地、材料、行政</small></div>
  <div><span>03</span><strong>估算單價</strong><small>查基準、詢價、核對限制</small></div>
  <div><span>04</span><strong>填入經費表</strong><small>單價 × 數量，註明用途</small></div>
</div>

## 一、經費編列參考

### 不同工作項目，可能需要哪些經費？

| 工作項目 | 可以先檢查的費用 |
| --- | --- |
| **培力課程** | 講師費、助教費、適用的補充保費、場地費、保險費、宣傳費、講師差旅、講義印製、臨時工資、材料費 |
| **社區體驗／走讀** | 導覽費、保險、名牌及走讀手冊印製、餐飲、單車或遊覽車租借、臨時工資、音響、材料與宣傳 |
| **僱工購料** | 工作費、材料、保險、餐費、器材租金 |
| **聘請專職人員** | 薪資、雇主負擔的勞健保、勞退及符合規定的其他人事成本 |
| **臨時人力** | 工資、可能適用的勞健保與其他法定雇主負擔 |
| **勞務委託** | 設計、創作、製作或其他勞務報酬；依交易對象與契約確認稅務及扣繳問題 |
| **舉辦市集** | 帳篷、桌椅及音響租借、清潔、臨時工資、交通管理、急救站、印刷、宣傳與設攤相關支出 |
| **演出活動** | 導演、排練、場租、售票平台費、保險、印刷、道具、服裝、劇本、田調與臨時人力 |

這張表不是要你每項都編，而是提醒自己：**一件工作從準備、辦理到撤場，有哪些實際支出？** 同樣辦工作坊，室內與戶外、10 人與 100 人，所需經費可能完全不同。

<div class="budget-check-card">
  <span class="budget-mini-label">容易遺漏的成本</span>
  <p>不只有活動當天的花費。整理場地、垃圾清運、設備搬運、保險、授權、稅金及工作人員的時間，都可能影響預算。若有合法勞動聘僱關係，也要估算應負擔的法定費用。</p>
</div>

如果還是不知道從哪裡找，可以再用下面這組經費名稱反向檢查：人事費、勞務費、講師費、出席費、稿費、差旅費、租金、材料費、食材費、印刷費、宣傳費、文具費、修繕費、水電費、郵電費、保險費、稅捐及雜支等。**名稱只能幫你盤點，能不能編列仍要看該案規定。**

## 二、經費編列依據

在臺灣，不論補助案或標案，經費往往不是隨意喊價。多數政府案件會提供經費編列原則、支給基準或契約要求。這些規定不必一次背下來，但要先知道：**經費有依據，不能只因為別人的表格這樣寫，就直接照抄。**

### 勞務與諮詢：先看人員支給基準

| 費用 | 常見參考依據 | 編列時注意 |
| --- | --- | --- |
| **講師鐘點費** | 《[講座鐘點費支給表](https://www.dgpa.gov.tw/FileConversion?filename=dgpa/files/201801/1e15732a-091f-4194-a9e3-e7a4c67d6e5e.docx&nfix=pdf&name=%E8%AC%9B%E5%BA%A7%E9%90%98%E9%BB%9E%E8%B2%BB%E6%94%AF%E7%B5%A6%E8%A1%A8.docx)》及各補助案基準 | 外聘、內聘與講座助理標準不同；外聘國內專家學者常見上限為每節 2,000 元，還要確認「一節」的計算方式 |
| **出席費、稿費** | 《[中央政府各機關學校出席費及稿費支給要點](https://ws.dgbas.gov.tw/001/Upload/461/relfile/10693/235615/19-%E4%B8%AD%E5%A4%AE%E6%94%BF%E5%BA%9C%E5%90%84%E6%A9%9F%E9%97%9C%E5%AD%B8%E6%A0%A1%E5%87%BA%E5%B8%AD%E8%B2%BB%E5%8F%8A%E7%A8%BF%E8%B2%BB%E6%94%AF%E7%B5%A6%E8%A6%81%E9%BB%9E.pdf)》 | 出席費有適用會議與人員條件，不是所有開會都能支付 |
| **顧問及專案人員** | 計畫規定、工作內容與市場行情 | 可以依工作範圍、經驗、聘期估算，必要時在經費表說明 |
| **臨時工資** | 當年度最低工資及勞動法令 | 不要拿舊年度範例單價直接編列；並留意實際聘僱型態 |

<div class="budget-rule-note">
  <strong>年度差異，別漏看</strong>
  <p>以 2026 年 10 月資料為例，最低時薪為 <strong>196 元</strong>，2027 年起調整為 <strong>205 元</strong>。中央政府出席費原上限為每次 <strong>2,500 元</strong>，已公告自 2027 年 1 月 1 日起調整為 <strong>3,000 元</strong>。這些是特定法規及生效時間的例子；實際案件仍應確認主管機關、補助簡章及適用年度。</p>
  <p class="budget-source-links">參考：<a href="https://www.mol.gov.tw/1607/28162/28166/28180/70460/76761/76833/post" target="_blank" rel="noopener noreferrer">勞動部歷年最低工資</a>、<a href="https://law.dgbas.gov.tw/LawContent.aspx?id=FL000752" target="_blank" rel="noopener noreferrer">主計總處出席費及稿費支給要點</a>。</p>
</div>

### 差旅、交通與行政雜項：不同機關可能有不同上限

差旅費可以查《[國內出差旅費報支要點](https://ws.dgbas.gov.tw/001/Upload/461/relfile/10693/234297/23-%E5%9C%8B%E5%85%A7%E5%87%BA%E5%B7%AE%E6%97%85%E8%B2%BB%E5%A0%B1%E6%94%AF%E8%A6%81%E9%BB%9E.pdf)》或《[國外出差旅費報支要點](https://ws.dgbas.gov.tw/001/Upload/461/relfile/10693/235615/24-%E5%9C%8B%E5%A4%96%E5%87%BA%E5%B7%AE%E6%97%85%E8%B2%BB%E5%A0%B1%E6%94%AF%E8%A6%81%E9%BB%9E.pdf)》，再分別估算交通、住宿與其他符合規定的費用。國外出差要特別注意不同城市的標準與匯率；交通是否實報實銷，也應依適用規定確認。

餐費、行政管理費、雜支等，最容易因為沿用別人的表格而出錯。有些計畫規定每餐 100 元、雜支不得超過總經費的 5%，或對行政管理費設有比例上限；**但這些都不是所有政府補助通用的標準**。不同機關、補助類型及年度，可能訂有不同上限，甚至不允許某些項目。

### 雜支不是什麼都能放

雜支通常是為了處理與計畫有關、金額較小又未另列的日常支出，例如零星文具、郵資、少量影印、會議消耗品或場地復原所需的小額用品。

雜支也要注意不重複編列。假如已經有「印刷費」項目，就不應又把同一批印刷支出放進雜支。設備與消耗品的判斷，更不能只看金額；還須看財產管理及該計畫對資本門與經常門的規定。

## 三、經常門與資本門是什麼？

公部門經費常會區分為兩種性質：**經常門**是維持業務運作及執行工作的支出；**資本門**則通常涉及購置、增置或改善具有較長期效益的資產。

| 比較 | 經常門 | 資本門 |
| --- | --- | --- |
| **核心概念** | 執行計畫所需的日常或當期支出 | 購置、增置、改善資產 |
| **常見用途** | 薪資、講師、活動、交通、印刷、材料 | 設備、部分資訊系統、建築或設施改善 |
| **使用效益** | 多與當期工作執行有關 | 通常可跨年度使用 |
| **地方實踐案例** | 辦 10 場社區課程的講師與材料費 | 購置長期使用的專業攝影設備 |
| **需要確認** | 支出是否符合核定科目及用途 | 是否允許購置、是否須登錄及保管財產 |

## 四、什麼是「勻支」，什麼是「流用」？

開始執行計畫後，實際支出不一定和預算完全相同。原本預計 30 人參加的工作坊，最後來了 50 人，材料費可能不足；原本要租的場地，後來借到免費空間，場地費可能剩下。

能不能把沒有花完的錢挪到另一項？這就要認識**勻支**與**流用**。兩者都涉及預算調整，但調整層級與核准要求可能不同。

    <span class="budget-mini-label">勻支 · 同一個一級科目下調整</span>
    <div class="budget-transfer-line"><span>場地費</span><strong>− 3,000</strong></div>
    <div class="budget-transfer-arrow">↓　二級科目間調整</div>
    <div class="budget-transfer-line"><span>材料費</span><strong>＋ 3,000</strong></div>
    <p>業務費總額仍為 30,000 元。</p>
  </div>
  <div class="budget-transfer-card">
    <span class="budget-mini-label">流用 · 不同一級科目之間調整</span>
    <div class="budget-transfer-line"><span>人事費</span><strong>− 50,000</strong></div>
    <div class="budget-transfer-arrow">↓　跨一級科目調整</div>
    <div class="budget-transfer-line"><span>業務費</span><strong>＋ 50,000</strong></div>
    <p>這裡只是說明跨一級科目調整的概念，<strong>人事費是否可以流用，仍須依各計畫規定確認</strong>。</p>
  </div>
</div>

### 勻支：同一個一級科目下的「小挪移」

例如一組社區課程的業務費原本編列如下：

| 經費細項 | 原編列 | 希望調整後 |
| --- | ---: | ---: |
| 材料費 | 10,000 元 | 13,000 元 |
| 場地費 | 8,000 元 | 5,000 元 |
| 講師費 | 12,000 元 | 12,000 元 |
| **合計** | **30,000 元** | **30,000 元** |

材料費多出 3,000 元需求，場地費則節省 3,000 元。這是同一業務費大項中細項間調整的示範，但**勻支不等於可以自行改表、先花再說**。有的計畫可依程序調整，有的必須事先報請核准。

### 流用：不同一級科目之間的「大挪移」

假設計畫原編人事費 50 萬元、業務費 50 萬元，因為聘人時間延後，人事費節省 5 萬元，團隊想把它增加到工作坊及教材費用。這就不是單純的業務費內部調整，而涉及不同一級科目之間的流用。

**人事費通常有較嚴格的流入、流出限制**，不少補助案也禁止經常門與資本門互相挪用。前面的數字只是用來說明概念，不能推論這 5 萬元一定可以合法調整。

| 比較 | 勻支 | 流用 |
| --- | --- | --- |
| **主要概念** | 同一經費大項內部調整 | 不同經費大項之間調整 |
| **對應層級** | 同一一級科目下的不同二級科目 | 不同一級科目之間 |
| **常見例子** | 場地費轉至材料費 | 人事費轉至業務費 |
| **總經費** | 通常不變 | 通常不變 |
| **核准程序** | 依計畫限制與調整幅度 | 通常限制更嚴格 |
| **跨經常、資本門** | 一般不涉及 | 應特別確認是否禁止 |

## 五、經費編列實際案例

### 假設要在豐田三村舉辦一場街區藝術展

假設依照**花蓮縣文化局 114 年社造點徵選簡章**的經費規定，要在豐田三村規劃一場街區藝術展。豐田三村具有移民歷史、多元族群文化與地方藝術資源，我們希望邀請返鄉及移居藝術家與居民共同創作，最後透過展覽和藝術走讀呈現地方文化。

## 六、經費編列表與下載

不同計畫的經費表格式不一定相同。有些會細分人事費、業務費、補助款與自籌款；有些會將單價、數量、單位與編列說明放在同一張表；也有些要求列出各大項占總經費的比例。**因此，填表前一定要先確認這個計畫要求哪些欄位。**

不論使用哪一種格式，建議至少檢查以下欄位：

| 欄位 | 要回答的問題 |
| --- | --- |
| 經費項目 | 這筆錢要用在什麼事情？ |
| 單價 | 每小時、每人、每場或每式多少錢？ |
| 數量、單位 | 要用幾小時、幾人、幾組、幾場？ |
| 總價 | 單價 × 數量是否正確？ |
| 補助款／自籌款 | 哪部分由補助支應、哪部分自行負擔？ |
| 編列說明 | 為什麼需要這筆支出？能對應哪個工作項目？ |
