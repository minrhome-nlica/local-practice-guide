社區協會申請政府計畫後，常常要支付講師費、活動工作費、設計費或稿費。明明跟對方說好報酬是 **100,000 元**，為什麼匯款時有時候只有 95,000 元，有時候是 90,000 元？

原因可能是「預扣所得稅」：付款單位在付錢之前，先扣下一部分，再代繳給國稅局。**先扣稅，不代表對方最後就要繳這麼多稅。** 這篇先談預扣所得稅；至於二代健保補充保費的 2.11%，請另看 [〈二代健保補充保費〉](/local-practice-guide/entries/supplemental-premium/)，兩套規定不能混在一起。

<div class="org-explainer-note"><strong>本文的試算範圍</strong><p>以下以 2026 年（民國 115 年）、收款人是臺灣境內居住的個人，且付款方是依法負扣繳義務的協會、公司等單位為例。境外居住者、特殊職業與其他所得類別，可能適用不同規定。</p></div>

## 一、什麼是預扣所得稅？

假設協會委託一位以個人名義執業的設計師製作主視覺，約定報酬 **100,000 元**，而且這筆報酬依法歸類為 9A 執行業務所得。

| 付款去向 | 金額 |
| --- | ---: |
| 約定設計報酬 | 100,000 元 |
| 預扣所得稅 10% | −10,000 元 |
| 設計師實際收到 | **90,000 元** |
| 協會代繳國稅局 | 10,000 元 |
| 協會總支出 | **100,000 元** |

協會沒有把 10,000 元留在自己帳戶，而是幫設計師先繳給國稅局。設計師隔年報綜合所得稅時，可以把先前扣繳的稅額拿來抵繳；有多扣就可能退稅，扣不夠則可能補稅。

## 二、9A、9B、50有什麼不同？

領據和扣（免）繳憑單上常見的 9A、9B、50，是**所得類別代碼**。它們不是任選的，必須依實際工作、契約及法律上的所得性質認定。

| 所得代碼 | 簡單理解 | 地方工作常見情境 |
| --- | --- | --- |
| **9A** | 執行業務所得 | 個人依法提供專業設計、攝影、藝術創作等執行業務報酬 |
| **9B** | 稿費、版稅等特定所得 | 符合規定的公開發表、刊登、出版稿費 |
| **50** | 薪資所得 | 社區課程講師費、臨時工作費、計畫人員薪資等 |

地方團體執行計畫時，**課程講師費與一般活動工作費多數會用到 50**。本篇不再重複討論「演講與授課」如何分類；需要查對具體所得性質時，可以參考先前的 [〈二代健保補充保費〉](/local-practice-guide/entries/supplemental-premium/)。

## 三、先分清楚：單次給付，還是單月給付？

這一步很重要。**扣繳所得稅不能一律把同一個月所有匯款加總，也不能一律每次匯款分開算。**

**單次給付**：通常指付款單位某一次實際支付報酬時，以該次給付金額判斷扣繳。9A、9B，以及 50 的「兼職或非每月給付薪資」，主要看這個基準。

**單月給付**：對於 50 的「每月固定薪資」，要依全月薪資總額及薪資扣繳規定處理。就算每月固定薪資分兩次匯款，也不能把兩次款項當作各自獨立的兼職薪資。

### 2026年常見的扣繳門檻

| 所得與給付方式 | 預扣規則 |
| --- | --- |
| **9A 執行業務所得** | 每次給付達 **20,010 元**，原則上扣 10% |
| **9B 稿費等所得** | 每次給付達 **20,010 元**，原則上扣 10% |
| **50 兼職、非每月給付薪資** | 每次給付達 **90,501 元**，原則上扣 5% |
| **50 每月固定薪資** | 依全月給付總額，按薪資扣繳稅額表或 5% 方式處理；依法有免扣繳規定 |

9A、9B 的 20,010 元，是因為境內居住者的執行業務所得，**每次應扣繳稅額不超過 2,000 元可免扣繳**：給付 20,000 元的 10% 正好是 2,000 元，可以免扣；給付 20,010 元才需扣 2,001 元。

50 兼職或非每月給付薪資的 90,501 元，則是 **115 年度（2026 年）**的起扣點，不能照搬其他年度的數字。

<div class="org-explainer-note"><strong>小提醒｜不要把「單次」和「單月」套用到二代健保</strong><p>這裡說的是所得稅扣繳。二代健保補充保費有自己的所得類別、起扣條件與計算方式；付款時要分別檢查。</p></div>

### 同樣分兩次付款，結果可能不一樣

假設協會聘一名計畫人員，每月固定薪資 60,000 元，因行政作業分成月初、月底各匯 30,000 元。這仍是**每月固定薪資 60,000 元**，應按全月金額及薪資扣繳規定處理，**不能因每筆都未達 90,501 元就直接免扣繳**。

反過來說，協會支付個人兼職工作報酬，不能只因為同一個月付了兩筆，就自動把它當成每月固定薪資。也不能為了避開扣繳，把原本同一次應給付的報酬刻意拆成多筆；應以真實給付關係判斷。

## 四、用四個社區工作案例來看

### 1. 婦女瑜珈課程：兼職講師費30,000元

協會邀請老師開設社區瑜珈課程，結束後一次支付 30,000 元，依法認定為 **50 兼職薪資所得**。

| 項目 | 金額 |
| --- | ---: |
| 講師費 | 30,000 元 |
| 預扣所得稅 | 0 元 |
| 講師實際收到（僅計所得稅） | **30,000 元** |

因為未達 90,501 元，這筆薪資**不用預扣所得稅**，但仍要依規定申報所得資料，並另外確認二代健保補充保費。

### 2. 活動工作費：一次支付100,000元

協會一次支付青年活動工作費 100,000 元，依法認定為 **50 兼職或非每月給付薪資**。

| 項目 | 金額 |
| --- | ---: |
| 工作費 | 100,000 元 |
| 預扣所得稅 5% | −5,000 元 |
| 實際收到（僅計所得稅） | **95,000 元** |

付款單位代繳國稅局 5,000 元，整筆原約定報酬仍是 100,000 元。

### 3. 設計委託：9A報酬100,000元

協會委託以個人名義執業的設計師製作海報，依法認定為 **9A**，一次給付 100,000 元，預扣 10,000 元，設計師先領 90,000 元。

但如果是向**已登記的商號或公司**購買服務並取得依法應開立的銷售憑證，就不能直接套用「付款給個人9A」這個案例。

### 4. 地方刊物稿費：9B報酬30,000元

協會出版地方文化刊物，支付符合 9B 規定的作者稿費 30,000 元。

| 項目 | 金額 |
| --- | ---: |
| 稿費 | 30,000 元 |
| 預扣所得稅 10% | −3,000 元 |
| 作者實際收到（僅計所得稅） | **27,000 元** |

符合規定的稿費、版稅等所得，還有**每人全年合計 180,000 元免稅**的規定。這與付款時是否先扣繳是兩件事；若最後計算不需要繳這筆所得的稅，預扣稅款可以在年度結算時依法抵退。

## 五、付款單位需要做什麼？

以協會實際辦理核銷、付款為例：

1. **付款前**：確認這筆錢付給個人還是商號／公司、所得代碼、約定含稅或實領金額，以及是單次或固定月薪。
2. **付款時**：依法計算扣繳稅額，保留領據、匯款資料、工作成果等必要憑證。
3. **付款後**：按期限把扣下的稅繳給國稅局。給付境內居住者的通常應於**次月10日前**繳納。
4. **年度申報**：依規定申報扣繳或免扣繳憑單。**沒有預扣，不代表不用申報所得資料。**

例如一位老師只領了 10,000 元兼職講師費，雖然沒有扣到所得稅，協會仍須留意免扣繳憑單申報規定；法規另有極小額給付免列單申報的例外。

<div class="org-explainer-note"><strong>付款前先說清楚</strong><p>簽約或確認費用時，建議直接寫明「約定報酬是多少」、「依法預扣後實領多少」，並確認是否還有二代健保補充保費。避免對方以為協會少付錢，也避免計畫經費編列和請款產生落差。</p></div>

## 六、結語

預扣所得稅的判斷順序，可以記成三步：**先看付給誰、再看9A／9B／50所得類別，最後確認是單次給付還是每月固定薪資。**

預扣所得稅不是最後的年度所得稅，也不是二代健保補充保費。申請計畫、編列經費與實際付款時，這三件事要分開處理。
