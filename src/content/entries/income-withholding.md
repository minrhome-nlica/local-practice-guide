社區協會申請政府計畫後，常常要支付講師費、活動工作費、設計費或稿費。明明跟對方說好報酬是 **100,000 元**，為什麼匯款時有時候只有 95,000 元，有時候是 90,000 元？

原因可能是「預扣所得稅」：付款單位在付錢之前，先扣下一部分，再代繳給國稅局。**先扣稅，不代表對方最後就要繳這麼多稅。** 這篇先談預扣所得稅；至於二代健保補充保費的 2.11%，請另看 [〈二代健保補充保費〉](/local-practice-guide/entries/supplemental-premium/)，兩套規定不能混在一起。

<div class="org-explainer-note"><strong>本文的試算範圍</strong><p>以下以 2026 年（民國 115 年）、收款人是臺灣境內居住的個人，且付款方是依法負扣繳義務的協會、公司等單位為例。境外居住者、特殊職業與其他所得類別，可能適用不同規定。</p></div>

## 一、什麼是預扣所得稅？

假設今天你是設計師，一個協會或公司，委託你以個人名義製作主視覺，約定報酬 **100,000 元**，而且這筆報酬依法歸類為**執行業務所得（代碼9A）**。

你會發現，你的收入如下：

| 你的報酬與扣款 | 金額 |
| --- | ---: |
| 約定設計報酬 | 100,000 元 |
| 預扣所得稅（10%） | −10,000 元 |
| **設計師實領** | **90,000 元** |

實際領到的錢只會有 **90,000 元**，並不是該協會或公司少給你錢，而是幫你先繳給國稅局。隔年報綜合所得稅時，這筆預先扣繳的 **10,000 元** 可以拿來抵繳；有多扣就可能退稅，扣不夠則可能補稅。

<strong>上述的案例，就是預扣所得稅：</strong>

預扣所得稅（即扣繳）是指企業、機關團體或個人在給付員工薪資、房東租金、執行業務報酬等所得時，依法先將一部分稅款扣留並預先繳納給國庫，而不是由所得人（如員工）在年度結算時一次繳交。

## 二、什麼是9A、9B、50？

**9A、9B、50是國稅局用來區分所得種類的「所得代碼」**，不是稅率，也不是政府計畫的經費科目。

當協會或公司支付報酬給個人，辦理所得扣繳與申報時，就會用這些代碼向國稅局說明：**這筆錢屬於哪一種所得。**

| 所得代碼 | 所得名稱 | 代表什麼意思？ |
| --- | --- | --- |
| **9A** | **執行業務所得（代碼9A）** | 個人以專業身分獨立提供服務所取得的執行業務收入，例如符合規定的專業設計、攝影等報酬。 |
| **9B** | **講演與稿費等收入（代碼9B）** | 符合規定的講演鐘點費、文章稿費、版稅等收入。 |
| **50** | **薪資所得（代碼50）** | 因提供工作而領取的薪水、工資、兼職工作費，以及符合薪資所得性質的課程講師費等。 |

例如協會辦理社區課程，支付給老師的授課費，實務上常見的是**薪資所得（代碼50）**；至於其他報酬應使用哪個代碼，仍須依實際工作與所得性質判斷，不能由付款單位自行任選。

**記住，代碼只是告訴國稅局這筆收入的類別，不是看到9A就一定扣10%、看到50就一定扣5%。** 要不要預扣、扣多少，還要看下一節的金額門檻與給付方式。

## 三、預扣所得稅扣繳門檻

以下以 **2026年（民國115年）**、臺灣境內居住的個人為例：

| 所得與給付方式 | 預扣規則 |
| --- | --- |
| **執行業務所得（代碼9A）** | 每次給付達 **20,010 元**，原則上預扣 **10%** |
| **講演與稿費等收入（代碼9B）** | 每次給付達 **20,010 元**，原則上預扣 **10%** |
| **薪資所得（代碼50）－兼職或非每月給付薪資** | 每次給付達 **90,501 元**，原則上預扣 **5%** |
| **薪資所得（代碼50）－每月固定薪資** | 依全月給付總額，按薪資所得扣繳稅額表或 **5%** 方式處理；依法有免扣繳規定 |

**薪資所得（代碼50）中，兼職或非每月給付薪資的90,501元**，是115年度（2026年）的起扣點，不能照搬其他年度的數字。

## 四、用四個社區工作案例來看

### 1. 婦女瑜珈課程：兼職講師費30,000元

協會邀請老師開設社區瑜珈課程，結束後一次支付 30,000 元，依法認定為**薪資所得（代碼50）**，且屬兼職薪資。

| 項目 | 金額 |
| --- | ---: |
| 講師費 | 30,000 元 |
| 預扣所得稅 | 0 元 |
| 講師實際收到（僅計所得稅） | **30,000 元** |

因為未達 90,501 元，這筆薪資**不用預扣所得稅**，但仍要依規定申報所得資料，並另外確認二代健保補充保費。

### 2. 活動工作費：一次支付100,000元

協會一次支付青年活動工作費 100,000 元，依法認定為**薪資所得（代碼50）**，且屬兼職或非每月給付薪資。

| 項目 | 金額 |
| --- | ---: |
| 工作費 | 100,000 元 |
| 預扣所得稅 5% | −5,000 元 |
| 實際收到（僅計所得稅） | **95,000 元** |

付款單位代繳國稅局 5,000 元，整筆原約定報酬仍是 100,000 元。

### 3. 設計委託：9A報酬100,000元

協會委託以個人名義執業的設計師製作海報，依法認定為**執行業務所得（代碼9A）**，一次給付 100,000 元，預扣 10,000 元，設計師先領 90,000 元。

但如果是向**已登記的商號或公司**購買服務並取得依法應開立的銷售憑證，就不能直接套用「付款給個人的執行業務所得（代碼9A）」這個案例。

### 4. 地方刊物稿費：9B報酬30,000元

協會出版地方文化刊物，支付作者稿費 30,000 元，這筆收入符合**講演與稿費等收入（代碼9B）**的規定。

| 項目 | 金額 |
| --- | ---: |
| 稿費 | 30,000 元 |
| 預扣所得稅 10% | −3,000 元 |
| 作者實際收到（僅計所得稅） | **27,000 元** |

<div class="org-explainer-note">
<strong>小提醒｜符合規定的9B相關收入，全年合計18萬元免稅</strong>
<p>依所得稅法，符合規定的稿費、版稅、樂譜、作曲、編劇、漫畫及講演鐘點費等收入，<strong>每人每年合計不超過180,000元，可以免納綜合所得稅</strong>。注意，這是同一個人<strong>整年度合計</strong>的金額，不是每接一筆案子就重新有18萬元免稅額度。</p>
<p>例如上面這筆30,000元的稿費，付款時雖然先預扣3,000元，但如果作者全年符合這項規定的收入合計未超過180,000元，先前扣繳的稅額就可以在年度報稅時依法申請抵退。若全年超過18萬元，超過的部分還可以依規定減除成本與費用後，再計算課稅所得。</p>
<p><strong>全年18萬元免稅，與付款當下要不要預扣是兩回事。</strong>這項免稅規定也不能直接套用到一般授課的薪資所得（代碼50）。可參考<a href="https://www.etax.nat.gov.tw/etwmain/tax-info/understanding/tax-q-and-a/national/individual-income-tax/taxation-scope/which-income/8qBnJYa" target="_blank" rel="noopener noreferrer">財政部說明</a>。</p>
</div>

## 五、付款單位需要做什麼？

以協會實際辦理核銷、付款為例：

1. **付款前**：確認這筆錢付給個人還是商號／公司、所得代碼、約定含稅或實領金額，以及是單次或固定月薪。
2. **付款時**：依法計算扣繳稅額，保留領據、匯款資料、工作成果等必要憑證。
3. **付款後**：按期限把扣下的稅繳給國稅局。給付境內居住者的通常應於**次月10日前**繳納。
4. **年度申報**：依規定申報扣繳或免扣繳憑單。**沒有預扣，不代表不用申報所得資料。**

例如一位老師只領了 10,000 元兼職講師費，雖然沒有扣到所得稅，協會仍須留意免扣繳憑單申報規定；法規另有極小額給付免列單申報的例外。

<div class="org-explainer-note"><strong>付款前先說清楚</strong><p>簽約或確認費用時，建議直接寫明「約定報酬是多少」、「依法預扣後實領多少」，並確認是否還有二代健保補充保費。避免對方以為協會少付錢，也避免計畫經費編列和請款產生落差。</p></div>

## 六、結語

預扣所得稅的判斷順序，可以記成三步：**先看付給誰、再確認執行業務所得（代碼9A）、講演與稿費等收入（代碼9B）或薪資所得（代碼50），最後判斷是單次給付還是每月固定薪資。**

預扣所得稅不是最後的年度所得稅，也不是二代健保補充保費。申請計畫、編列經費與實際付款時，這三件事要分開處理。
