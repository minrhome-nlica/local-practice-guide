假設我是一名設計工作者，平常承接活動海報、主視覺及品牌設計等工作。

今天有一間公司委託我製作一套活動主視覺，雙方約定設計費為 **100,000 元**。

如果我以個人身分接案，和成立工作室、公司接案，稅務上有什麼不同？如果我是社團法人或合作社的成員，又會產生哪些差異？

同樣是 100,000 元的設計費，因為承接案件的身分不同，收款方式、所得認定，以及付款單位需要處理的事情，都可能不一樣。

這篇就讓我們分別代入六種情境，看看不同身分在稅務上的差別。

為了方便比較，前五個案例都以同一筆 100,000 元的設計服務為基礎。假設付款方是臺灣境內公司，100,000 元為未含應外加營業稅的服務價格；若承接者依法須開立 5% 應稅發票，則另加營業稅 5,000 元。

## 一、個人身分接案

### 1. 假設我是一名自由接案的設計師

我沒有成立工作室，也沒有加入公司，平常就是自己接案。

某間公司找我製作活動主視覺，約定支付 100,000 元。

完成設計後，我以個人名義請款。

但對方在匯款之前告訴我，必須先扣除所得稅，還可能扣除二代健保補充保費。

為什麼明明談好 100,000 元，實際匯進戶頭的錢卻變少了？

### 2. 個人接案會被扣多少錢？

假設這筆設計報酬依法認定為執行業務所得（9A），而且我是臺灣境內居住者，並符合應扣取二代健保補充保費的條件：

| 項目 | 金額 |
| --- | ---: |
| 設計報酬 | 100,000 元 |
| 預扣所得稅 10% | −10,000 元 |
| 二代健保補充保費 2.11% | −2,110 元 |
| **實際匯入帳戶** | **87,890 元** |

<div class="tax-withholding-note" data-rate="10" role="note" aria-label="小提醒：預扣10%不是最終所得稅">
  <span class="tax-withholding-kicker">小提醒｜先扣稅，不等於最後繳這麼多</span>
  <strong class="tax-withholding-title">預扣 10%，不代表最後一定繳 10% 的所得稅</strong>
  <p>公司先扣下的 10,000 元，是替我<strong>預繳到國稅局</strong>，不是公司自己留下，也不是另外多收一筆稅。隔年申報綜合所得稅時，要用全年的所得、必要費用、免稅額及扣除額等計算真正的稅額，再扣掉已預繳的稅款。</p>
  <p>例如全年結算後，假設我總共應繳 8,000 元所得稅，且先前只預扣了 10,000 元，就可能退還多繳的 2,000 元；如果應繳 15,000 元，則可能還要補繳 5,000 元。這些是假設的年度結算金額，不是本案確定稅額。</p>
</div>

另外，**二代健保補充保費不等於所得稅**，也不是所有人領取執行業務收入都一定需要扣取。例如以執行業務所得作為投保金額的特定被保險人，可能符合免扣取條件。補充保費也不能直接拿來抵繳個人綜合所得稅。

而且，不是所有設計工作都一定屬於 9A。實際所得類別還要看委託內容、創作性質與工作關係。

### 3. 那付款公司要付出多少錢？

這是比較容易被忽略的部分。

雖然我只實領 87,890 元，但付款公司並不是只花了 87,890 元。

| 付款去向 | 金額 |
| --- | ---: |
| 匯給設計師 | 87,890 元 |
| 代繳國稅局所得稅 | 10,000 元 |
| 代繳健保署補充保費 | 2,110 元 |
| **付款公司合計支出** | **100,000 元** |

換句話說，**所得稅和個人補充保費是從原本 100,000 元報酬中扣下來的，不是付款公司另外多付 12,110 元。**

但是，付款公司需要額外處理相關行政作業，包括確認所得性質、製作領據、依法扣繳及申報所得資料，並依規定扣取與繳納補充保費。

如果這筆交易實質上是僱傭關係，而非獨立承攬，則可能改按薪資所得處理，付款公司也可能增加勞健保、勞退與其他雇主負擔。

此外，公司取得合規的個人領據及付款證明，可以依規定認列必要支出，但因為沒有取得可扣抵進項稅額的統一發票，不能據此扣抵 5% 營業稅。

### 4. 如果改成邀請設計師授課，付款公司會多付多少錢？

現在我們把情境改變一下。

我仍然是同一名設計師，但這次公司不是委託我製作海報，而是邀請我為員工開設一系列設計課程，教授視覺設計、排版與軟體操作。

雙方同樣約定支付 100,000 元。

但這一次，因為工作內容變成授課，所得的分類可能不一樣，甚至會影響付款公司的實際成本。

**首先，要先區分「授課鐘點費」與「講演鐘點費」。**

這裡最重要的觀念是：**不是名稱叫做「講師費」，就一定屬於薪資所得 50。** 必須依實際工作內容判斷。

接下來，我們假設這次是一系列設計訓練課程，依法認定為薪資所得 50。

#### （1）設計師實際可以領到多少錢？

假設我是臺灣境內居住者，這筆 100,000 元屬於一次給付的兼職授課薪資，並符合個人兼職薪資補充保費的扣取條件。

依此情境試算：

| 項目 | 金額 |
| --- | ---: |
| 設計課程講師費 | 100,000 元 |
| 預扣薪資所得稅 5% | −5,000 元 |
| 個人兼職薪資補充保費 2.11% | −2,110 元 |
| **講師實際收到** | **92,890 元** |

<div class="tax-withholding-note" data-rate="5" role="note" aria-label="小提醒：預扣5%不是最終所得稅">
  <span class="tax-withholding-kicker">小提醒｜5% 是預扣，不是最後的稅率</span>
  <strong class="tax-withholding-title">預扣 5%，不代表最後只需要繳 5% 的所得稅</strong>
  <p>這裡預扣的 5,000 元和前面設計費預扣 10,000 元一樣，都是公司先代扣、替講師繳給國稅局的稅款。<strong>真正應納多少所得稅，還是要等隔年申報全年綜合所得稅時結算。</strong></p>
  <p>例如全年結算後，假設講師應繳所得稅 3,000 元，且只有這筆 5,000 元扣繳稅額，就可能退還 2,000 元；如果全年應繳 8,000 元，就可能補繳 3,000 元。預扣 5% 比 10% 少，不代表這種工作最終必然比較省稅。</p>
</div>

在這個案例裡，因為所得認定為薪資所得 50，而不是執行業務所得 9A，所以所得稅扣繳方式有所不同。

依 **2026 年（民國 115 年）**規定，境內居住者取得非每月給付的薪資或兼職所得，原則上按 5% 扣繳；每次給付未達 **90,501 元**者，符合規定可免予扣繳。本案例一次給付 100,000 元，因此按 5% 試算；一般按月給付薪資另有扣繳規定。

而且，假設我是在其他單位投保健保，這次收到的 100,000 元屬於非所屬投保單位給付的兼職薪資，並符合扣費條件，付款公司便須從報酬中扣取 2.11% 的個人補充保費。

這筆 2,110 元仍然由講師個人負擔，**且不能直接拿來抵繳綜合所得稅**。

#### （2）付款公司為什麼可能還要額外付 2.11%？

前面談的 2,110 元，是從講師報酬中扣下來的。

但是，**如果這筆講師費屬於薪資所得 50，付款公司還可能需要額外負擔另一筆「投保單位補充保費」。**

依二代健保制度，投保單位每個月支付的薪資所得總額，若超過當月受僱者健保投保金額總額，就必須針對差額按 2.11% 計算補充保費。

計算公式如下：

**投保單位補充保費＝（當月支付薪資所得總額－當月受僱者健保投保金額總額）× 2.11%**

如果差額小於或等於 0，就沒有這筆差額補充保費。

舉例來說，假設付款公司原本的薪資情況如下：

| 項目 | 金額 |
| --- | ---: |
| 公司原本當月支付員工薪資總額 | 500,000 元 |
| 公司原本當月受僱者健保投保金額總額 | 500,000 元 |
| 額外支付設計課程講師費（所得 50） | +100,000 元 |
| **當月薪資所得總額** | **600,000 元** |
| 扣除受僱者健保投保金額總額 | −500,000 元 |
| **應計收補充保費的差額** | **100,000 元** |
| **投保單位額外補充保費 2.11%** | **2,110 元** |

這代表什麼？

原本公司支付 100,000 元的設計委託費用，假設屬於 9A 執行業務所得，這筆支出不會列入公司計算投保單位補充保費的薪資總額。

但如果改成薪資所得 50 的授課費，這筆 100,000 元就會計入當月支付的薪資所得總額。

在前面設定的薪資條件下，**公司因此需要額外支付 2,110 元補充保費。**

不過，必須再次提醒：這是依公司整個月的薪資總額與投保金額總額計算，**不是所有所得 50 都一律另外加收 2.11%**。例如公司原本的薪資總額就低於投保金額總額，新增講師費後仍未超過，就可能不需要繳納這筆補充保費。

前者從講師原本的報酬中扣除；後者則是在符合條件時，由付款公司自己另外支付，不能直接從講師已約定的報酬中再扣一次。

還有一件事需要釐清：表格中講師實領比較高，主要是因為兩種所得的**預扣稅率不同**。預扣較少不代表最終所得稅一定較低，仍要在年度所得稅申報時結算。

這個案例說明了一件很重要的事：

**對付款單位而言，不同所得類別不只是扣繳方式不同，也可能影響單位需要額外負擔的成本。**

因此，當我們規劃活動、編列講師費、設計費等經費時，不能只看約定要支付多少報酬，還要確認所得性質、個人補充保費及投保單位是否有額外負擔。

若想了解詳細計算方式，可以搭配[〈二代健保補充保費〉](/local-practice-guide/entries/supplemental-premium/)詞條閱讀。

### 5. 個人接案真的比較划算嗎？

如果只是偶爾承接設計案件，個人接案可能相對單純。

但如果我已經持續對外提供服務，經常有大量案件，甚至開始聘請其他人協助，就需要進一步確認營業性質與登記義務。

**個人接案的好處是行政程序可能較少，但不代表不用報稅，也不代表永遠最省稅。**

## 二、商號／工作室接案

### 1. 假設我成立了自己的設計工作室

隨著接案逐漸穩定，我成立「豐田設計工作室」，並依法完成相關登記。

這次一樣承接 100,000 元的設計案，但由工作室與客戶簽約、收款。

對方希望我提供統一發票。

假設我的工作室已經由國稅局核定使用統一發票，而且這筆設計服務適用 5% 營業稅：

| 項目 | 金額 |
| --- | ---: |
| 設計服務費 | 100,000 元 |
| 營業稅 5% | 5,000 元 |
| **客戶付款金額** | **105,000 元** |

這次工作室實際收到 105,000 元，其中 5,000 元是銷項營業稅，不應直接當成工作室賺到的利潤。

### 2. 成立商號之後，所得稅怎麼處理？

如果我成立的是獨資商號，就不能直接把它當成有限公司。

在現行制度下，獨資商號的營利所得，原則上歸入負責人的個人綜合所得稅計算。

例如工作室一年有 100 萬元營業收入，扣除依法可認列的成本與費用後，核定營利所得為 60 萬元。

這 60 萬元原則上會歸入我的個人綜合所得稅，而不是先像一般有限公司一樣繳納 20% 營所稅，再將股利分配給自己。

但商號仍須依規定處理營業稅、帳務及適用的申報程序；符合小規模營業人條件者，也可能由國稅局查定課徵，而不是使用統一發票。

### 3. 付款公司要付出多少錢？

假設工作室依法開立 105,000 元的應稅統一發票：

| 項目 | 金額 |
| --- | ---: |
| 支付工作室設計費 | 100,000 元 |
| 支付營業稅 | 5,000 元 |
| **實際付款** | **105,000 元** |

和個人領據不同，付款公司取得依法開立的營業人發票後，通常不需要就這筆一般營業交易，再代扣個人的 10% 執行業務所得稅或 2.11% 個人補充保費。

而且，如果付款公司本身是依法適用一般加值型營業稅的營業人，這筆設計費是供其應稅業務使用，且取得符合規定的進項憑證，**其中 5,000 元營業稅可能可以申報扣抵銷項稅額**。

也就是說，雖然付款時匯出 105,000 元，但其中 5,000 元可能不是最終的營業稅負擔。

不過，如果付款單位的業務不能扣抵進項稅額，這 5,000 元就可能成為實際成本。

### 4. 工作室比較節稅嗎？

工作室的好處，不只是能夠依法申請使用統一發票。

當我開始長期經營，有固定的設備租賃、委外設計、交通及其他經營成本時，完整的帳務管理可以幫助我依法計算營利所得。

但成立工作室不代表所有私人支出都能拿來節稅，也不代表一定比個人接案少繳稅。

**對長期經營的接案工作者來說，商號真正的優勢，是讓營業活動、收入與成本逐漸建立制度。**

## 三、公司接案

### 1. 假設我成立了一間有限公司

後來，我的設計業務越來越穩定。

除了自己設計，我還聘請其他設計師、購買設備，也希望有能力承接更大的活動與品牌專案。

於是，我成立了一間有限公司。

這次同樣承接 100,000 元設計案，由公司開立應稅發票。

客戶支付 105,000 元，款項匯入公司帳戶。

**但這 105,000 元是公司的收入與代收稅額，不是我個人的收入。**

即使公司 100% 股份都由我持有，我和公司在法律上仍然是不同的主體。

### 2. 公司需要繳多少稅？

公司對外提供應稅設計服務，原則上需要依法處理 5% 營業稅。

此外，公司還需要計算年度營利事業所得稅。

例如，我的公司一年營業收入 100 萬元，依法認列的成本與費用合計 40 萬元。

假設最後課稅所得額為 60 萬元，適用 20% 營所稅率：

| 項目 | 金額 |
| --- | ---: |
| 年度營業收入 | 1,000,000 元 |
| 假設可認列成本與費用 | −400,000 元 |
| 課稅所得額 | 600,000 元 |
| 公司營所稅 20% | 120,000 元 |
| **公司階段稅後所得** | **480,000 元** |

但不能因為公司繳完 120,000 元營所稅，就認為剩下 480,000 元已經是我個人的免稅收入。

如果我要從公司取得收入，可能透過合理薪資或依法分配股利。這些款項還涉及個人所得稅；公司保留盈餘也有相應的稅務規定。

### 3. 付款公司需要付出多少錢？

在這筆 100,000 元設計案中：

| 項目 | 金額 |
| --- | ---: |
| 公司設計服務費 | 100,000 元 |
| 營業稅 5% | 5,000 元 |
| **付款公司合計支出** | **105,000 元** |

付款方依發票及交易資料辦理帳務，符合條件的 5,000 元進項稅額可以申報扣抵。

一般而言，這種公司對公司、依法開立發票的境內營業交易，不會像支付個人執行業務報酬一樣，代扣 10% 個人所得稅與 2.11% 個人補充保費。

如果我是付款公司的員工，而不是外部公司的承攬者，那就會變成另一種聘僱與薪資關係，不能混為一談。

### 4. 公司真的比較節稅嗎？

公司可能有更完整的營運彈性，例如依法支付工作人員薪資、保留盈餘與投入設備。

但公司也有記帳、申報、人事及管理成本。

如果把公司繳納的營所稅、股東未來可能繳納的股利所得稅，以及經營成本全部算進去，就會發現：

**成立公司不一定比較省稅，但對持續經營、聘用人員與擴大事業規模的人而言，可能是更適合的組織形式。**

## 四、社團法人接案

### 1. 假設我在一間地方文化協會工作

接下來換個情境。

我是一名設計師，也是一間地方文化協會的工作人員。

協會平常推動地方文化保存、社區活動及青年培力。

某間公司希望委託協會辦理文化推廣計畫，其中包含主視覺設計，並約定支付 100,000 元。

這次由協會簽約，款項也是匯入協會帳戶。

但我不能因為自己是協會理事長、會員或工作人員，就把這 100,000 元當成自己的錢。

因為**協會的收入是組織收入，而不是會員或負責人的個人收入。**

### 2. 協會不是非營利組織嗎？為什麼還要繳稅？

很多人以為，社團法人是非營利組織，就不需要繳稅。

其實不是。

符合規定的教育、文化、公益、慈善機關團體，特定所得可能適用所得稅免稅規定。

但如果協會對外提供設計、活動執行或其他收費服務，仍要看交易性質，判斷是否需要繳納營業稅，以及如何處理相關所得稅。

**不能因為收款的是協會，就認為 100,000 元一定免稅。**

此外，政府補助、會員會費、捐款，以及提供勞務取得的服務費，性質也可能不同，需要分別處理。

### 3. 付款公司要付出多少錢？

假設這筆委託屬於協會依法應課徵 5% 營業稅、並須開立統一發票的服務：

| 項目 | 金額 |
| --- | ---: |
| 設計服務費 | 100,000 元 |
| 營業稅 5% | 5,000 元 |
| **付款公司合計支出** | **105,000 元** |

付款公司取得合法發票後，依相關規定辦理成本、費用與營業稅扣抵。

但如果委託的是符合特定免稅規定的活動或服務，發票及營業稅處理就可能不同。

另外，如果付款方是一個不能扣抵進項營業稅的單位，即使取得 105,000 元的應稅發票，也不代表能把其中 5,000 元抵掉。

### 4. 那我在協會工作，可以領取收入嗎？

可以依法取得合理的工作報酬。

例如協會聘請我擔任設計人員，依法支付薪資；或是協會委託外部設計師完成工作，依契約給付報酬。

這些支出需要依實際工作關係，處理所得申報、扣繳及可能適用的勞健保費用。

但**協會依法支付薪資、設計費，不等於可以把年底的結餘分紅給會員**。

因此，社團法人的稅務優勢並不是讓個人把自己的設計收入轉進協會後，再免稅領回。

它更重要的意義，是能將資源留在組織內，持續投入符合宗旨的公共事業。

## 五、合作社接案

### 1. 假設我和其他設計師成立合作社

再來，我和幾位設計工作者希望共同經營事業。

我們一起成立合作社，希望分享設備、共同承接案件，並透過社員之間的合作降低成本。

這次一樣有公司委託設計活動主視覺，費用 100,000 元。

如果合作社的章程與業務範圍允許承接這項委託，便可以由合作社簽約、收款，再由社員依約分工完成。

但是，合作社有免稅優惠，這筆設計費就一定免稅嗎？

### 2. 合作社有哪些稅務優惠？

《合作社法》第 7 條規定，合作社得免徵所得稅及營業稅。

但**這並不是說，只要成立合作社，所有對外交易都自動免稅**。

例如合作社依法經營特定社員內部業務，符合營業稅法規定時，可能適用免稅。

不過，今天委託設計的公司不是合作社社員。

所以，這筆 100,000 元的對外設計服務，不能直接套用社員內部交易的營業稅免稅規定。

所得稅部分也需要依實際交易及相關稅法判斷，不能把營業稅免稅與所得稅免稅當成同一回事。

### 3. 付款公司需要付出多少錢？

假設合作社依法提供這項設計服務，交易適用 5% 營業稅並開立應稅發票：

| 項目 | 金額 |
| --- | ---: |
| 合作社設計服務費 | 100,000 元 |
| 營業稅 5% | 5,000 元 |
| **付款公司合計支出** | **105,000 元** |

付款公司取得合法發票後，依規定認列費用，並判斷進項稅額是否可以扣抵。

但如果合作社提供的是依法免徵營業稅的特定貨物或服務，就不能直接套用這個加收 5% 的算法。

### 4. 合作社收到的錢，最後怎麼分配？

合作社和社團法人有一個重要差別：合作社依法可以依其制度處理結餘分配。

例如涉及社員提供勞務、共同使用設備、分配股息或按交易量分配結餘時，都有不同的規定。

但不能把合作社收到的 100,000 元直接當作我的個人所得，也不能認為只要按照社員工作量分配，就完全不用申報個人所得稅。

社員實際取得的款項，仍要依給付性質判斷所得稅處理。

**合作社的優勢，是讓有共同需求的人可以共同經營、分享資源與成果；稅務優惠是其中的一項可能利益，而不是唯一目的。**

## 六、農民自產自銷，為什麼可能享有不同的稅務待遇？

### 1. 假設我是一名種植蔬菜的農民

最後我們換一個身分。

我是一名花蓮農民，平常種植高麗菜與其他季節蔬菜。

今年收成不錯，一間餐飲公司希望直接向我購買 100,000 元的高麗菜。

這些高麗菜是我自己種植、採收，沒有經過加工。

餐飲公司直接向我購買，我也不需要為了這一筆交易成立公司。

那麼，我收到的 100,000 元需要繳營業稅嗎？

### 2. 自產自銷的生鮮農產品，可以免徵營業稅

依《加值型及非加值型營業稅法》第 8 條相關規定，未經加工的生鮮農產品，以及農民銷售自身收穫的農作物，符合適用條件時，可以免徵營業稅。

因此，在這個案例裡，我直接販售自己種植、未經加工的高麗菜，符合規定時：

| 項目 | 金額 |
| --- | ---: |
| 高麗菜銷售金額 | 100,000 元 |
| 營業稅 | 0 元 |
| **農民收款金額** | **100,000 元** |

這和一般設計公司提供應稅服務、另外加收 5% 營業稅的情況不同。

但要注意，這裡討論的是**農民出售自己生產的農作物**，以及未加工生鮮農產品的免稅規定。

如果我不是農民，而是向其他農民收購蔬菜再轉賣，或是將農產品加工成其他商品，就要另外判斷適用的營業稅與所得稅規定，不能直接把所有農產品買賣都認定為免稅。

### 3. 農民取得的收入，個人所得稅怎麼算？

農民以自己勞力從事農業生產所取得的收入，可能屬於綜合所得稅中的「自力耕作所得」。

它不是在法律上完全不存在的所得類別。

不過，財政部對自力耕作收入另訂有成本及必要費用標準。

例如依 **114 年度（2025 年）自力耕作漁林牧收入成本及必要費用標準**，符合規定的農業收入，其成本及必要費用得按收入的 100% 減除。

假設符合該年度標準的自力耕作收入為 100,000 元：

| 項目 | 金額 |
| --- | ---: |
| 自力耕作收入 | 100,000 元 |
| 依該年度標準減除成本及必要費用 100% | −100,000 元 |
| **計算所得額** | **0 元** |

這就是為什麼一般農民從事真正的農業生產，在所得稅上也可能享有相當特殊的待遇。

不過，必要費用標準按年度公告，115 年度（2026 年）收入應以該年度發布的規定為準，不能直接把前一年度標準當成永久不變的規定。

### 4. 那購買農產品的餐飲公司要付出多少錢？

從付款方的角度，這筆交易也和委託設計師不同。

| 項目 | 金額 |
| --- | ---: |
| 向農民購買高麗菜 | 100,000 元 |
| 營業稅 | 0 元 |
| **餐飲公司合計支出** | **100,000 元** |

餐飲公司並不是把這 100,000 元當成支付設計師的執行業務報酬，因此不能直接套用個人設計師的 10% 所得稅扣繳及 2.11% 補充保費計算。

不過，餐飲公司仍然需要取得合法的進貨憑證。

例如農民可以依實際交易開立收據，記載購買日期、農產品名稱、數量、單價、總金額及相關簽章資料。

公司據此記錄進貨成本，也應保存付款及進貨紀錄。

**農民不需要開立應稅統一發票，不代表購買方就可以完全不留下任何憑證。**

此外，因為這筆生鮮農產品交易免徵營業稅，付款公司並沒有另外支付 5,000 元的進項營業稅，自然也不能憑這筆交易扣抵不存在的 5,000 元進項稅額。

這也是為什麼農民、農產運銷合作社、一般蔬果批發商與農產加工公司，雖然可能都在販售農產品，稅務處理卻不一定相同。

回到最初的問題。

同樣是一筆 100,000 元的交易，我們用不同身分收款，可能有以下差別：

可以發現，個人接案不一定最省稅；成立商號、公司或其他組織，也不代表每一筆交易就能少繳稅。

而且站在付款方的角度，**支付個人報酬、支付公司設計費、向農民購買蔬菜，是三種不同的交易**。

甚至是支付給同一位設計師，委託他製作海報與邀請他來授課，因為所得性質不同，也可能產生不同的扣繳義務與單位成本。

因此，我們在判斷哪一種身分比較有利時，不只要問自己會繳多少稅，也要思考：

1. 我能夠使用哪些合法憑證向客戶請款？
2. 客戶需要額外支付營業稅嗎？有沒有辦法扣抵？
3. 我取得的收入需要怎麼申報？有哪些必要成本可以認列？
4. 我需要負擔多少記帳、行政及人事成本？
5. 未來我希望只是自己持續接案，還是建立一個可以長期經營的事業或組織？

**成立組織不只是為了節稅，而是讓原本依靠個人能力完成的工作，有機會逐漸發展成更穩定、能夠共同經營的事業。**

如果已經有穩定的工作收入、合作機會與經營需求，就值得進一步評估成立商號、公司、合作社或社團法人的可能性，而不是只因為擔心增加稅務成本，就始終停留在個人接案。
