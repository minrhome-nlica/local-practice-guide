第一次寫計畫的人，通常會記得編列「專案人員薪資」，卻忘記員工每個月領薪水以外，單位還要負擔多少費用。假設你想聘請一位月薪 32,000 元的計畫助理，經費表只寫每月 32,000 元，就可能少算了勞保、健保、勞工退休金，以及其他依法應負擔的費用。

這篇先不談「二代健保補充保費」，而是從**真正雇用一名員工**開始。延續我們習慣的教學方式，先看誰要繳、再看級距、最後直接算一次：**員工可以實領多少？單位實際要準備多少錢？**

## 一、勞保、健保和勞退不是同一筆錢

我們習慣把它們統稱「勞健保」，實際上是幾套不同的制度，法定負擔對象也不完全相同。

| 項目 | 主要用途 | 一般受僱者如何負擔 |
| --- | --- | --- |
| **勞工保險** | 生育、傷病、失能、老年及死亡等保障 | 勞工、投保單位及政府依比例分擔 |
| **就業保險** | 失業給付、育嬰留職停薪津貼等 | 勞工、投保單位及政府依比例分擔 |
| **職業災害保險** | 工作中發生職災時的保障 | 一般受僱者由投保單位負擔保費 |
| **全民健康保險** | 醫療保障 | 一般受僱者、投保單位與政府分擔；眷屬也影響個人負擔 |
| **勞工退休金（勞退新制）** | 雇主按月提繳至勞工個人退休金專戶 | 適用者由雇主至少提繳 6%；勞工可另自願提繳 |

這裡最容易弄錯的是**勞退 6% 不是雇主從員工的薪水扣走的錢**。適用勞退新制的受僱勞工，雇主必須在約定工資之外，額外提繳至少 6% 至個人專戶；只有勞工選擇「自願提繳」時，才會另有從其工資扣繳的部分。

<div class="insurance-compare" aria-label="員工與單位的薪資成本差別">
  <div><span>員工看的數字</span><strong>約定薪水 − 員工自付保費</strong><p>還可能受到自願提繳勞退、所得稅扣繳及其他合法項目影響。</p></div>

## 二、不是只有正職員工才要注意投保

地方計畫有時聘專職行政，有時找工讀生、短期活動人員，還可能請設計師、講師或耆老協助。**判斷是不是勞動僱傭關係，不能只看支領的名目叫「工作費」、「講師費」或「委託費」。**

| 常見情況 | 先確認什麼？ |
| --- | --- |
| **聘請專職計畫助理** | 到職後依組織性質、適用保險與身分辦理加保、提繳；不能只編薪水 |
| **工讀生、部分工時人員** | 雖然不是全職，也可能須依規定加保及提繳；級距另有部分工時規則 |
| **僅有少數員工的協會或工作室** | 不能以「未滿五人」直接推論什麼保險都不用辦；就保、災保、健保及勞退仍須各自判斷 |
| **外聘講師、獨立承攬設計師** | 確認是受僱還是獨立提供服務；不能因為簽了領據，就一律當成雇員或一律不必投保 |
| **只做一天的活動協助人員** | 仍要判斷是否屬實際受僱，以及適用的加退保或短期工作規定 |

有些單位不滿五人，不一定是勞保強制投保單位，卻仍可能需要辦理就業保險、職災保險、健保及勞退。**各保險要分開檢查**，不要只憑勞保這一項來判斷全部的人事義務。

## 三、2026 年勞健保級距，究竟怎麼看？

投保級距是把實際月薪對照到法定分級表，不一定直接用原本的薪水計算。舉例來說，月薪 **32,000 元**，落在「31,801～33,300 元」之間，所以全時一般受僱者對應的投保金額是 **33,300 元**。

但要注意，**勞保、健保與勞退有各自的分級表**。2026 年勞保一般受僱者的月投保薪資最高級距為 45,800 元，健保則有更高的分級；勞退也有自己的月提繳工資分級表，不能把一張表當成所有制度的唯一級距。

## 四、實際算一次：月薪 32,000 元，要花多少錢？

假設協會聘請一位月薪 32,000 元的專職助理，依法參加勞保、就保與健保，適用勞退新制；先假設**沒有健保眷屬、沒有自提勞退、全月在職，也不考慮所得稅扣繳**。

從上表可以找到 33,300 元這一級。接著把員工負擔、雇主負擔分開：

| 項目 | 員工負擔 | 單位負擔 |
| --- | ---: | ---: |
| 勞保＋就業保險 | 833 | 2,914 |
| 全民健康保險 | 516 | 1,611 |
| 勞退新制 6% | 0（未自提） | 1,998 |
| **合計** | **1,349** | **6,523** |

所以，月薪 32,000 元的員工，不一定會實領 32,000 元；協會要編列的人事成本，也不會只有 32,000 元。**這個例子的每月基本成本至少是 38,523 元，再加上依行業費率計算的職業災害保險費及其他適用成本。**

請特別記得：員工自付的 1,349 元，是從已約定的 32,000 元薪水中依法扣繳；**不能把它再加一次到雇主成本裡**。單位額外負擔的是 6,523 元及其他依法應負擔費用。

## 五、聘人以前，先把成本與文件想清楚

寫計畫書時，可以先用以下順序檢查：

1. **確認工作型態**：是專職、部分工時、短期受僱，還是獨立承攬？先依實際工作關係判斷。
2. **確認加保義務**：勞保、就保、職災保險、健保、勞退分別適用哪些規定；不要把「未滿五人」當作全面免辦。
3. **核實約定薪資**：不只看底薪，也要依規定辨認哪些給付屬工資或薪資所得。
4. **對應各制度級距**：勞保、健保、勞退不一定有相同上限；部分工時與不滿一個月另算。
5. **拆開列經費**：月薪、雇主負擔保險費、勞退、職災保險及其他可能費用，避免預算漏編。
6. **保留相關紀錄**：聘僱文件、薪資清冊、出勤紀錄、加退保資料、繳款及提繳證明等，依適用法規與補助核銷要求留存。

實務上，我們更建議不要等到要送[核銷資料](/local-practice-guide/entries/reimbursement/)時，才回頭問「為什麼每個月除了薪水，還要繳一堆費用？」從[經費編列](/local-practice-guide/entries/budget-planning/)階段就要把這些支出考慮進去。

## 六、結語：接下來要認識二代健保補充保費

前面討論的，是**為員工投保及提繳所發生的一般成本**。但是社區組織辦理計畫時，還經常支付外聘講師費、兼職報酬、表演費或年終獎金，這時可能遇到另一套規定：**全民健康保險的補充保險費**。

那又分成兩件事：單位自己需要繳的補充保費，以及單位在付款時要從個人所得中代扣的補充保費。下一篇[〈二代健保補充保費〉](/local-practice-guide/entries/supplemental-premium/)會把這兩件事分開算清楚。
